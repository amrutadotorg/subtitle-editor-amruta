# Known issues and stale artifacts

Things that look like bugs or inconsistencies and are intentional (or at least known). Read this before "fixing" them.

| Item                                                                             | Reality                                                                                                                                                                                                                                            |
| -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `components.json` references `tailwind.config.ts`                                | Stale shadcn artifact. Tailwind 4 configures via CSS in `app/globals.css`. **Do not create a `tailwind.config.ts`.**                                                                                                                               |
| React Compiler enabled (`reactCompiler: true`)                                   | Intentional. Do not disable it to work around a rendering issue.                                                                                                                                                                                   |
| `react-hooks/set-state-in-effect` disabled for a file list in `eslint.config.js` | Legitimate autosave/restore and hook-wiring pattern. Do not re-enable globally.                                                                                                                                                                    |
| `fast-xml-parser` pinned to `5.7.1` in overrides                                 | Deliberate pin. See [dependencies.md](dependencies.md).                                                                                                                                                                                            |
| 2-line subtitle limit                                                            | Product rule, not a bug: the editor allows at most 2 lines per cue. Splitting into separate cues is the expected workflow.                                                                                                                         |
| `scratch.js` in the repo root                                                    | Ad-hoc MP4 debugging script, not part of the build. Safe to ignore; do not wire it into scripts.                                                                                                                                                   |
| `TODO.md` and `TODO_2.md` in the repo root                                       | Polish-language **technical audit reports** from July 2026, covering a fork state that predates the Vimeo removal. They are not a task list and are partly obsolete. Do not treat their findings as current without verifying against the code.    |
| `/faq` link in the narrow-screen notice                                          | `app/[locale]/page.tsx` passes `faqHref: "/faq"`, but no `app/faq` route exists (only `app/best-practices`). The link currently 404s. Confirm with the owner whether the destination should be `/best-practices` or a new page before changing it. |
| nginx `location /api/vimeo/` rate-limited block                                  | Leftover from the removed Vimeo download integration. Harmless (nothing matches it), but stale. Remove only alongside a deliberate nginx config change.                                                                                            |
| `public/_headers`                                                                | Cloudflare-Pages artifact; unused in this nginx deployment.                                                                                                                                                                                        |
| `docs/superpowers/plans/*`                                                       | Historical design notes for shipped features (peaks cache, last position, Vimeo removal). Useful context, not current specs.                                                                                                                       |
| `README.md`                                                                      | Written for a human audience and lags reality in places (e.g. it references `app/faq`). This documentation set is authoritative for agent work.                                                                                                    |
| `audit.log` in the repo root                                                     | Output of an old `npm audit` run; not consumed by any tooling.                                                                                                                                                                                     |

## If you are tempted to "clean these up"

Check `git log` for the rationale first — several of the above were deliberate trade-offs recorded in commit messages (`docs(pwa): document webpack build for next-pwa and the gotchas`, `docs: record minimatch override rationale`). Do not silently remove a guardrail or a pin to make a check pass.
